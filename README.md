```mermaid
flowchart LR
    A[Push] --> B[GitHub]
    B --> C[Jenkins Trigger]
    C --> D[Build & Test]
    D --> E[SonarQube\nQuality Gate]
    E --> F[Trivy\nVulnerability Scan]
    F --> G[Docker Build]
    G --> H[Docker Push]
    H --> I[Deploy → AWS EC2]
    I --> J[Health Check]

    style A fill:#0A0E14,stroke:#00E5FF,color:#00E5FF
    style B fill:#0A0E14,stroke:#00E5FF,color:#00E5FF
    style C fill:#0A0E14,stroke:#00E5FF,color:#00E5FF

$ pipeline run --project brilliant-pipeline

✔ Pipeline succeeded — deployed to production in 1m14s
```
